# ⭐ Edu Job Scraper Bot

A Flask + Selenium automation tool that scrapes the latest IT job postings from EdJoin across multiple Southern California counties.  
It launches a headless Chrome browser, parses listings with BeautifulSoup, and displays all results in a clean, sorted UI.

## 🚀 Features

### 🌎 Scrapes job postings from:
- 🟦 **San Bernardino County**
- 🟩 **Riverside County**
- 🟧 **Orange County**
- 🟥 **Los Angeles County**

### 🔍 Extracts job details:
- 🧑‍💼 **Job Title**
- 🏫 **District Name**
- 💵 **Salary**
- 📅 **Deadline**
- 🔗 **Direct Posting URL**

### 📊 Additional Functionality:
- ⬇️ Sorts posts by **newest posting ID first**
- ⚡ Uses **headless Selenium** for dynamic page loading
- 🌐 Simple, clean **Flask UI** to view results
